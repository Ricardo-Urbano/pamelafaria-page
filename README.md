# Pamela Faria Nail Designer

Página profissional da Pamela Faria, nail designer em Criciúma - SC. O site apresenta os principais serviços, canais de contato, cursos presenciais e uma área preparada para futuras recomendações de produtos com links afiliados.

## Acessos

- Site: https://ricardo-urbano.github.io/pamelafaria-page/
- Domínio personalizado: https://pamelafaria.com.br
- Página de cursos: https://ricardo-urbano.github.io/pamelafaria-page/cursos/
- Página de produtos: https://ricardo-urbano.github.io/pamelafaria-page/produtos/

## Recursos

- Página inicial responsiva, com foco em acesso pelo celular.
- Agendamento direto pelo WhatsApp.
- Localização do studio em Criciúma - SC com rota pelo Google Maps.
- Links para Instagram, WhatsApp e Google Meu Negócio.
- Página exclusiva para os cursos da Pamela Faria.
- Cursos para iniciantes e aperfeiçoamento.
- Vídeos demonstrativos dos cursos.
- Avaliações de alunas.
- Página preparada para produtos e links afiliados.
- Identidade visual em preto, branco e cinza.

## Estrutura

```text
.
├── index.html              # Página inicial
├── styles.css              # Estilos da página inicial
├── script.js               # Scripts da página inicial
├── cursos/
│   ├── index.html          # Página de cursos
│   └── styles.css          # Estilos da página de cursos
├── produtos/
│   ├── index.html          # Página de produtos favoritos
│   └── styles.css          # Estilos da página de produtos
├── assets/
│   ├── images/             # Imagens do site
│   └── videos/             # Vídeos dos cursos
└── CNAME                   # Domínio personalizado
```

## Desenvolvimento local

O projeto é uma página estática e não precisa de instalação de dependências. Para visualizar, abra o `index.html` no navegador ou use um servidor local, como a extensão Live Server do VS Code.
